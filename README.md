# indieHub

Indie oyun yayinlama ve satin alma platformu. Tauri + React + Supabase ile gelistirilmistir.

## Kurulum

```bash
npm install
npm run dev
```

## Tauri ile masaustu uygulamasi

```bash
npm run tauri dev
```

## Ortam degiskenleri

`.env.local` dosyasi olustur:

```
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key
```
